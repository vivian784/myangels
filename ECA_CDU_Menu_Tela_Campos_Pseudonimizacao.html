Modelo de estrutura seguido: CDU.pdf (Nome do CDU / Objetivo / Contexto Atual / Fluxo Proposto / Regras de Negócio)
Fontes cruzadas: ECA_Tela_x_CDU_rascunho.pdf (Menu/Tela → CDU) + ECA_Dados_ADM_v2.pdf (Tela → Campo/Categoria/Técnica)
SR 114853 — ECA - Cenário 2

Como ler este documento

  • Cada bloco representa um CDU (ou um agrupamento de telas sem CDU localizado).
  • Quando a planilha de origem não indicou um CDU correspondente para a tela, o campo Nome do CDU está marcado como "Não localizado" — para validação posterior.
  • A coluna Técnica de Pseudonimização Sugerida replica exatamente a recomendação já validada no levantamento de dados (ECA_Dados_ADM_v2), sem alteração.
  • Duas linhas do levantamento de origem vieram sem Categoria/Técnica preenchidas; aqui aparecem como "A definir".

Regra Geral de Pseudonimização

Aplica-se a todos os CDUs deste documento, exceto onde houver nota específica.
  • O sistema verifica o atributo beneficiário_menor_de_idade (booleano, calculado a partir da data de nascimento — ver CDU_INFRA) do beneficiário/titular dos dados exibidos na tela.
  • Quando verdadeiro, os campos listados na tabela "Campos e Pseudonimização" de cada CDU passam a ser exibidos de forma pseudonimizada, conforme a técnica indicada.
  • Perfis com a permissão "Acessa dados de menores de 18 anos" (beneficiario_dados_menor_de_18_anos — ver CDU_ADM - Manter Perfil) continuam visualizando os dados completos; os demais perfis visualizam pseudonimizado.
Fluxo Proposto (padrão):
  1. Usuário ADM acessa a tela.
  2. Sistema consulta o atributo beneficiário_menor_de_idade do beneficiário/titular associado ao registro.
  3. Se verdadeiro e o perfil do usuário logado não possuir a permissão "Acessa dados de menores de 18 anos", o sistema aplica a técnica de pseudonimização indicada a cada campo listado.
  4. Se o perfil possuir a permissão, ou o beneficiário for maior de idade, os dados são exibidos de forma integral (comportamento atual, sem alteração).

CDUs de Geolocalização — Novas Funcionalidades

Mesma regra já aprovada em CDU_APP - Consultar Guia Médico (CDU.pdf), replicada para as demais funcionalidades do app que utilizam geolocalização/proximidade.

CDU_APP - Consultar Unimed Mais Próxima

Objetivo: Garantir que a geolocalização permaneça desabilitada por padrão para beneficiários menores de 18 anos na funcionalidade "Unimed Mais Próxima", preservando as demais formas de busca.
Contexto Atual: A busca por proximidade depende de GPS ativo/autorizado pelo dispositivo; hoje não há distinção de comportamento por faixa etária do beneficiário.
Fluxo Proposto:
  1. Sistema consulta o atributo beneficiário_menor_de_idade do beneficiário logado.
  2. Se verdadeiro, a opção de ordenação "Mais próximo" não é exibida — permanece apenas "Ordem alfabética" (ou equivalente já usado no Guia Médico).
  3. O sistema não solicita/aciona automaticamente o GPS do dispositivo; a busca exige inserção manual de cidade/localização.
Regras de Negócio:
  • "Ordenar por": para menor de 18 anos, exibe apenas "Ordem alfabética" — suprime "Mais próximo".
  • Localização habilitada: não obrigatória; não solicitada automaticamente para menor de 18 anos.
  • Raio de busca padrão / barra de distância / conversão KM-metros: não exibidos para menor de 18 anos (mesma supressão aplicada ao Guia Médico).
  • Ativação de geolocalização para o beneficiário menor permanece controlada exclusivamente pelo responsável legal, via toggle "Geolocalização" na tela "Permissões do Beneficiário" (CDU_APP - Permitir acesso às informações).
